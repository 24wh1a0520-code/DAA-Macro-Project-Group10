ORIGINAL FACULTY PROMPT
-----------------------
"Illustrate recursive division of matrices in Strassen's algorithm."

Expected Outcome: "Block diagram of submatrix operations."


DETAILED VISUALIZATION PROMPT
-----------------------------
Create a clean, professional academic block diagram titled
"Strassen's Matrix Multiplication - Recursive Division".

The visualization must emphasize the RECURSIVE DIVISION of matrices into
submatrices and the FLOW OF SUBMATRIX OPERATIONS, so that the
Divide-and-Conquer idea is clearly visible. Use boxes and arrows, readable
mathematical notation, and do not overcrowd the diagram. The flow (top to
bottom) must be:

START
  |
  v
Input Matrix A and Input Matrix B
(example: A = [[1, 2], [3, 4]], B = [[5, 6], [7, 8]])
  |
  v
DIVIDE Matrix A into:        DIVIDE Matrix B into:
   A11 | A12                    B11 | B12
   A21 | A22                    B21 | B22
  |
  v
Show the seven Strassen multiplication operations (CONQUER):
   M1 = (A11 + A22)(B11 + B22)
   M2 = (A21 + A22) B11
   M3 = A11 (B12 - B22)
   M4 = A22 (B21 - B11)
   M5 = (A11 + A12) B22
   M6 = (A21 - A11)(B11 + B12)
   M7 = (A12 - A22)(B21 + B22)
  |
  v
Show how the seven products are combined:
   C11 = M1 + M4 - M5 + M7
   C12 = M3 + M5
   C21 = M2 + M4
   C22 = M1 - M2 + M3 + M6
  |
  v
COMBINE the four submatrices:
   C11 | C12
   C21 | C22
  |
  v
Final Matrix C   (C = [[19, 22], [43, 50]])

Requirements: show clearly that each matrix is divided into four
submatrices, that only SEVEN multiplications are used (instead of eight),
and that the results are combined to build the final matrix. Do not include
unrelated algorithms. The diagram must match Project5_Strassen.py and
README.md exactly.
